# TXT转EPUB工具
一个能自动识别txt小说文件中的章节、分卷标题，将其转换为epub电子书格式的工具
## 安装方法
### 【选项1】直接下载打包好的.exe文件
点进Releases下载即可
### 【选项2】利用源码运行
本脚本依赖pypandoc_binary，可使用`pip install pypandoc_binary`一键安装
## 使用说明
在第一个弹窗选择你要转换的.txt文件，在第二个弹窗输入小说作者名字（单纯为了后续排版好看，可忽略）。输出的.epub文件会与输入文件放在同一目录下。

程序通过检测分卷、章节开头的标题字符串（例如：第一卷、第三十五章、86、七百二十等等），完成分卷、分章与标题分级操作，过程中会生成.md文件，可以选择删除。
