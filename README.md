# TXT转EPUB工具
一个能自动识别txt小说文件中的章节、分卷标题、作者姓名，将其转换为epub电子书格式的工具。

⚠警告：如果原始txt文件中并无明确、统一的分章标题，那么转换后的epub会丢失第一个规整分章前的所有内容。
## 安装方法
### 【选项1】直接下载使用
点进Releases下载即可，分单独可执行文件与压缩包两个版本。
### 【选项2】利用源码运行
本脚本依赖pypandoc_binary，可使用`pip install pypandoc_binary`一键安装。
## 使用说明
在弹窗中选择你要转换的txt文件。输出的epub文件会与输入文件放在同一目录下。

程序通过检测分卷、章节开头的标题字符串（例如：第一卷、第三十五章、86、七百二十等等），完成分卷、分章与标题分级操作。
